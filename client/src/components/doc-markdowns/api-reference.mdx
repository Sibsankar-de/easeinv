# API Reference

This document describes the endpoints available in the EaseInv API. For authentication instructions, please refer to the [Authentication Guide](/docs/authentication).

---

## Products API

Manage your store catalog and product inventory.

### 1. List Products
`GET /v1/products`

Retrieve a paginated list of products for the active store.

**Response (200 OK)**
```json
{
  "success": true,
  "data": [
    {
      "id": "prod_01J0EAW",
      "name": "Wireless Ergonomic Mouse",
      "sku": "WRLS-MSE-01",
      "buyingPrice": 15.00,
      "sellingPrice": 29.99,
      "stock": 42,
      "currency": "USD"
    }
  ]
}
```

### 2. Create Product
`POST /v1/products`

Add a new product to your inventory.

**Request Body**
```json
{
  "name": "Bluetooth Mechanical Keyboard",
  "sku": "KB-MECH-87",
  "buyingPrice": 45.00,
  "sellingPrice": 89.99,
  "stock": 15
}
```

## Invoices API

Create, update, and fetch invoice records.

### 1. List Invoices
`GET /v1/invoices`

Retrieve a list of drafted and paid invoices.

### 2. Create Invoice
`POST /v1/invoices`

Create a new billing invoice transaction.

**Request Body**
```json
{
  "customerId": "cust_01J0EBF",
  "items": [
    {
      "productId": "prod_01J0EAW",
      "quantity": 2
    }
  ],
  "taxRate": 8.5,
  "discount": 5.00,
  "paymentMode": "UPI"
}
```

## Orders API

Manage customer orders, track fulfillment states, and dispatch packages.

### 1. List Orders
`GET /v1/orders`

Retrieve a paginated list of orders with status, customer, and search filters.

### 2. Create Order
`POST /v1/orders`

Place a new order for a customer. Product prices are calculated server-side and an automatic draft invoice is created.

**Request Body**
```json
{
  "customerId": "cust_01J0EBF",
  "couponCode": "SUMMER10",
  "shippingAmount": 50,
  "note": "Please leave at reception",
  "invoiceData": {
    "billItems": [
      {
        "productId": "prod_01J0EAW",
        "netQuantity": 2,
        "stockUnit": "pcs"
      }
    ]
  }
}
```

### 3. Update Order Status
`PATCH /v1/orders/:orderId/status`

Update the lifecycle state of an order (`PROCESSING`, `DISPATCHED`, `COMPLETED`, `REJECTED`). Completing an order automatically issues the linked invoice and decrements product inventory.

**Request Body (Dispatched)**
```json
{
  "status": "DISPATCHED",
  "deliveryReference": "TRK-987654321",
  "note": "Dispatched via Express Delivery"
}
```
